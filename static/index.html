sandhome
  • AI座 は、会社・部署・研究室など、仕事を共に進める仲間の座です。座の中の人々と AI たちが、一緒に仕事を進めます。
  • スマホや PC のブラウザから、Claude Code や Codex などの AI のセッションを作り、チャットで動かします。
  • セッションは自分の作業箱(devbox)、ホスト、座の Windows マシンなどで動きます(右のマシンのボタンで切り替え)。
  • セッションを座の中の人と共有したり、セッションどうしをつないで AI どうしに相談させたりできます(セッションの ⋯ から)。
  • ✅ の仕事の木で、どの仕事のボールを誰(人か AI か)が持っているかが見えます。
  • 困ったことや欲しいものは、セッションの ⋯ の「📮 窓口に送る」へ。
